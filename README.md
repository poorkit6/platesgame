# Номерной джекпот — проект Android

Игра — это один файл `app/src/main/assets/index.html`, внутри приложения он открывается в WebView.
Если захотите что-то поменять в игре, правьте этот файл и пересобирайте APK.

## Способ 1. Android Studio (самый простой)

1. Установите Android Studio: https://developer.android.com/studio
2. `File → Open` и выберите эту папку (`PlatesGameAndroid`). Дождитесь окончания Gradle Sync
   (студия сама скачает всё нужное, включая Android SDK 34).
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Скопируйте его на телефон и установите
   (разрешите установку из неизвестных источников).

Либо подключите телефон по USB (включите «Отладку по USB») и нажмите зелёную кнопку ▶ Run.

## Способ 2. Без установки Android Studio — облако GitHub

1. Создайте на github.com пустой репозиторий и загрузите в него содержимое этой папки
   (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions → Build APK → Run workflow**.
3. Через несколько минут внутри запуска появится артефакт **PlatesGame-apk**. Скачайте его, внутри `app-debug.apk`.

## Способ 3. Командная строка

Нужны JDK 17+ и Android SDK (переменная `ANDROID_HOME`):

    ./gradlew assembleDebug      # Windows: gradlew.bat assembleDebug

APK появится в `app/build/outputs/apk/debug/`.
`./gradlew assembleRelease` соберёт `app-release.apk` (подписан отладочным ключом, для личной установки этого достаточно).
Для публикации в Google Play нужен собственный ключ и `bundleRelease`.

## Что внутри

- `MainActivity.java` — WebView на весь экран, сохранение прогресса через localStorage, кнопка «Назад» закрывает окна и вкладки игры.
- Минимальная версия Android — 8.0 (API 26). Ориентация — только портретная.
- Иконка приложения нарисована векторно (`res/drawable`).

## Быстрая проверка игры в браузере

Откройте `app/src/main/assets/index.html` в Chrome. Если дописать к адресу `#lucky`, известные номера
будут выпадать очень часто, удобно посмотреть анимацию легендарного номера.

## Автосалон: свои машины без пересборки APK (версия 1.2+)

При первом запуске приложение просит доступ к файлам и создаёт на телефоне папку **PlatesGame**
(Файлы → Внутренняя память → PlatesGame). В ней:

- `my_cars.txt` — список ваших машин, по одной в строке: `салон | цена | название | файл картинки`
  (салон: низкий, средний, высокий, премиум или эксклюзив). Пример: `высокий | 5 000 000 | Моя машина | my-car.jpg`
- `cars/` — сюда кладите картинки. Если файл в строке не указан, ищется `cars/<название машины>.jpg` (или .png/.webp).
  Картинки можно положить и для стартовых машин, имена файлов лежат в `cars/СПИСОК_ИМЁН.txt`.

После правок откройте вкладку «Автосалон» и нажмите «Обновить список». Пересобирать APK не нужно.
`my_cars.txt` можно править любым текстовым редактором на телефоне (например, Markor или QuickEdit).
Если доступ к файлам не выдан, папка создаётся в данных приложения: `Android/data/com.platesgame.app/files`
(на новых Android её видно не во всех файловых менеджерах), поэтому лучше разрешить доступ.

Стартовый список машин (`cars.js`) по-прежнему зашит в приложение. Если положить свой `cars.js` в папку PlatesGame,
он заменит встроенный.

## Выдача и удаление через файл (версия 1.3+)

В папке PlatesGame (рядом с `my_cars.txt`) появляются ещё два файла:

- `give.txt` — сюда пишете команды, по одной в строке. Игра выполняет их при запуске и по кнопке
  «Обновить список» (вкладка «Автосалон»), после чего стирает.
  - `номер | А777АА77 | сейф | 50 000 000` — выдать номер (любой; место «коллекция»/«сейф» и цена не обязательны)
  - `машина | Bugatti Divo` — машина из автосалона; `машина | Моя тачка | 3 000 000` — любая своя с вашей ценой
  - `удалить номер | А777АА77` (или `все`, `коллекция`, `сейф`), `удалить машину | Bugatti Divo` (или `все`)
  - `баланс | +5 000 000` добавить, `баланс | -1 000` убавить, `баланс | 10 000 000` установить
  Неудавшиеся строки остаются в файле с пометкой `# ОШИБКА` и причиной.
- `save.txt` — ваше текущее состояние (баланс, коллекция, сейф, гараж). Игра обновляет его сама, править его не нужно.

Купленные и выданные машины видны на вкладке «Гараж» внутри автосалона.

## Правка кода игры на телефоне (версия 1.5+)

В игре: меню «⋯» → «🛠 Код игры» → «Вынести код в папку». В PlatesGame появится `index.html` (весь код игры).
Правьте его любым редактором и перезапустите игру, пересобирать APK не нужно. Приложение берёт `index.html`
из папки PlatesGame, если он там есть. Если игра перестала запускаться, удалите этот файл из папки.
После обновления APK нажмите «Вернуть оригинал» (или удалите файл), иначе останется старая версия игры.

## Обновление поверх старой версии

Начиная с версии 1.1 APK подписывается постоянным ключом (`app/debug.keystore`).
Если у вас стоит APK из более ранней сборки, один раз удалите его с телефона и поставьте новый
(прогресс игры при этом сбросится). Дальше новые версии будут ставиться поверх старых с сохранением прогресса.
